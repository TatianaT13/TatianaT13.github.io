Dépenses

Un gestionnaire de dépenses privé pour iPhone. Tout reste sur votre appareil.

Questions fréquentes

Où sont stockées mes données ?

Sur votre iPhone uniquement, chiffrées par iOS. L'app n'a pas de serveur et ne demande aucun compte.

Comment ajouter une dépense rapidement ?

Avec le bouton + dans l'app, le widget « Nouvelle dépense » sur l'écran de verrouillage, ou en disant à Siri « Ajoute une dépense dans Dépenses ».

Comment scanner un ticket ?

Dans la saisie rapide, touchez l'icône de document en haut à droite, puis prenez une photo ou choisissez-en une. Le montant, le commerçant et la date sont lus directement sur votre iPhone.

Comment verrouiller l'app ?

Réglages → Sécurité → Verrouiller avec Face ID. L'app demandera Face ID, Touch ID ou votre code à chaque ouverture.

Comment supprimer mes données ?

Supprimez l'app : toutes ses données partent avec elle, car rien n'est stocké ailleurs.
